# 2026-08-02 フル体験デモ手順（デモブランチ限定・終了後に削除）

PC(録音)+スマートフォン(確認・承認・絵日記)でLittle Echoesのフル体験を見せる手順。
実在する子どもの声は使わず、大人の演じ分け(台本: `main/docs/fixed-sample-script.md`)を使う。

## 事前準備（デモ開始前に1回）

1. 封止解除の反映（`main/apps/api-worker/wrangler.toml`の`DEMO_WRITE_ENABLED = "true"`は設定済み）:

   ```powershell
   ./.tools/wrangler-local.ps1 deploy
   ```

   デプロイ出力の`env.DEMO_WRITE_ENABLED ("true")`を確認する。

2. PCクライアントを起動し、マイクとトークンを確認:

   ```powershell
   uv run python main/apps/pc-client/src/main.py
   ```

   - デバイストークンは環境変数`LITTLE_ECHOES_DEVICE_TOKEN`、未設定なら起動時に入力
   - 送信先は既定で`https://ingest.in0ho1no.com`

3. スモークテスト: 台本どおりに1件録音→アップロード→スマホ(`app.in0ho1no.com`、Accessログイン)で
   確認待ちに出ることを確認。解析完了(`確認待ち`表示)まで見ておくと当日安心。

## デモの流れ（10分想定）

1. **録音(PC)**: 台本メイン(約13秒)を演じ、ボタン1.5秒長押しで確定 → 自動アップロード
2. **確認(スマホ)**: 確認待ち一覧 → 録音詳細。文字起こしと単語候補(ワンワン/ブーブー/バイバイ)を見せる。
   音声再生も可能
3. **承認(スマホ)**: 必要なら候補を編集し「承認する」
4. **絵日記(スマホ)**: 絵日記詳細で日記文の自動生成を待つ(進捗スピナー表示) → 「画像を生成」で
   イラスト生成(確認ダイアログに残数表示) → 完成した絵日記とNEWことばスタンプを見せる
5. **ことば辞典(スマホ)**: 初出単語が辞典に載っていることを見せる

## 上限メモ（日次はUTC日単位、残数は日記詳細の「生成できる回数」カードに表示）

- 録音作成: 30/日
- テキスト系AI(文字起こし・単語抽出・日記文): 100/日
- 画像生成: 20/日、録音ごとに通算5回

## 失敗時の復旧

- 解析失敗: 録音詳細に理由と「自動解析を再試行」(1回)が出る。だめなら手動で文字起こし・単語を入力して承認
- 日記生成失敗: 「手動で保存」で日記文を直接入力できる。「日記文を生成」の再実行は1回だけ
- 画像生成失敗: 既存画像は維持される。再試行するか画像なしで進める
- 画面が止まって見える場合: 再読み込み(ポーリングは180回で停止する設計)

## デモ終了後の後始末

1. デモで作った録音を管理画面から削除する(削除は封止後も完了まで動く)
2. 再封止: `wrangler.toml`を`DEMO_WRITE_ENABLED = "false"`へ戻して再デプロイし、
   出力の`("false")`を確認
3. `デモ`ブランチを丸ごと削除する(ユーザー実施)
4. Accessへ一時追加したアドレスがあれば失効する
